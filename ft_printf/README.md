# Ft_prinf - Recoding of original printf function in C

# Description

The goal of this project is pretty straightforward. I recoded printf().
It is about using a variable number of arguments. It is pretty cool!
You will discover variadic functions in C.

# ft_printf.c

Consist of one main function and two helper functions: ft_dispatch
and handle_char. Where handle_char is handling format string,
passing it to ft_dispatch where it runs other suitable print function
passing argument to it

# Instructions
